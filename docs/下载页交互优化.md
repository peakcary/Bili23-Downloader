# 下载页交互优化

本轮优先让用户直接看到队列状态并调整同时下载的任务数，沿用现有 Fluent 控件与页面布局。

## 已实现

- 下载页工具栏下显示正在下载数、排队数、失败数和总下载速度。统计来自源列表，搜索和筛选不会改变全队列摘要。
- 页面直接调整同时下载数，范围 1 至 10，沿用现有调度配置并保存。提高上限后调度排队任务；调低上限不强制暂停正在下载的任务。
- 提示多个任务共享带宽，单任务线程数仍在设置页调整，避免混淆两类并发。
- 与设置页双向同步，使用配置项信号刷新控件，避免修改一处后另一处显示旧值。
- 摘要仅在下载标签页显示。隐藏时停止一秒刷新定时器，重新显示立即刷新；数字不包含暂停任务遗留的速度。
- 加入简体与繁体翻译并编译资源。

“正在下载”只计网络传输状态，不包含解析和合并；“排队”只计下载等待，不包含等待合并。后续可根据实际使用增加独立的解析、合并、暂停状态摘要。

## 验证和范围

新增测试覆盖全队列状态统计、排除非下载任务遗留速度、配置保存与设置同步。已检查 440 像素宽的独立组件截图，文案可换行且控件没有重叠。完整主窗口、深色主题及 Windows/Linux 视觉验收尚待完成。

本轮不改变任务卡片、失败详情、批量选集和解析页。这些作为后续独立改动，避免同时改变所有操作入口。

开发分支为 `feat/download-overview`；工作区同时保留上一轮尚未提交的性能测速工具、实测文档和直连连接池修复，提交时应明确范围。
