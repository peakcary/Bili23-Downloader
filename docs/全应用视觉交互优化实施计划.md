# 全应用视觉交互优化实施计划

覆盖解析、选集、下载选项、任务管理、收藏、历史、登录、设置及辅助窗口。目标是让用户清楚知道“选了什么、会下载什么、操作影响哪些任务、下一步怎么处理”，沿用现有 Qt Fluent 控件体系。

## 实施原则

- 先解决误选、操作范围和反馈，再统一布局与视觉细节。
- 保留已有能力：范围选集、搜索、筛选、下载内容预览均已有实现，优先完善。
- 一个操作区只保留一个主按钮；删除和清除降低视觉权重。
- 不改变账号、下载目录和用户默认设置；本次选项和长期默认值需要清晰区分。
- 每批独立验证；不将源代码修改等同于已替换应用包。

## 页面规划与验收

| 页面或入口 | 改造方向 | 验收标准 | 阶段 |
| --- | --- | --- | --- |
| 主导航 | 以新建下载、下载任务、我的内容、历史组织流程；账号和设置置底，关于降级为辅助入口 | 登录、收藏返回后保留原解析与勾选；不出现无实现的空入口 | 二 |
| 解析首页 | 明确支持的链接类型、粘贴并解析、解析中防重复、失败保留输入 | 单次解析只有一份结果；错误后可直接重试 | 一、三 |
| 解析列表 | 正片与附加内容分组计数；附加组默认折叠；下载按钮显示数量 | 一眼区分正片与花絮，不按标题误合并不同视频 | 一 |
| 范围选集 | 明确行号与集数区别、输入校验、去重预览，后续支持分组范围 | `1，3,5-10` 可用；非法、多连字符及越界范围不崩溃；保留原勾选 | 一 |
| 批量解析 | 每个链接显示处理中、成功、失败；允许只重试失败项 | 单条失败不清空其他结果；不能重复提交正在处理的链接 | 二 |
| 下载确认 | 数量、画质、音轨、弹幕、字幕、目录汇总；主按钮具体到数量 | 提交前可明确知道是否会下载弹幕，以及文件保存位置 | 一 |
| 下载选项 | 可调整窗口大小；预览与按钮区分行布局；标注本次与默认设置范围 | 长路径、全部附加文件标签同时出现时不遮挡按钮；取消行为与提示一致 | 一、三 |
| 下载中列表 | 当前列表批量操作范围、可用操作数、行多选、状态对应主操作 | 筛选后的操作不影响隐藏任务；合并中不提供无效暂停 | 一、二 |
| 已完成列表 | 播放、打开位置为常用入口；清除记录和删除文件分开 | 清除记录明确保留文件；文件缺失给出可行动反馈 | 一、二 |
| 收藏与个人内容 | 将短暂浮层改为稳定浏览页面，登录后回到原位置 | 翻页、滚动、勾选不因查看详情丢失 | 二 |
| 历史记录 | 强调标题、类型、时间和重新解析，保留搜索 | 无需复制链接即可重新解析；清空历史不影响下载文件 | 二 |
| 登录与账号 | 二维码为默认入口，短信分标签、Cookie 放高级入口 | 二维码过期可刷新；关闭登录不破坏当前任务 | 二 |
| 设置 | 分类导航与搜索；给每项标明立即、新任务或重启生效 | 搜索结果跳转并突出目标；并发变更解释对运行任务的影响 | 一、二 |
| 命名规则 | 用真实样例预览目录与完整文件名 | 多集、特殊字符、重名结果可预见；不只展示占位符 | 二 |
| 弹幕与字幕 | 区分独立文件、封装字幕及播放器自动加载 | 用户能理解为何视频播放时出现文字；配置与任务快照一致 | 一、二 |
| 重复任务提示 | 展示旧任务状态、画质和文件是否存在；本批选择与永久偏好分开 | 用户可查看原任务，不因默认记忆导致长期误跳过 | 一 |
| 错误提示 | 概述问题、保留输入、提供重试或对应设置入口 | 能从失败任务进入相关日志；不能只给异常堆栈 | 二 |
| 媒体检查 | 先显示结论，再显示轨道和技术信息；统一 Fluent 风格 | 明确结构检查不等同全片解码；保存失败单独反馈 | 三 |
| 日志 | 从失败任务进入时按上下文筛选；复制诊断信息脱敏 | 不复制 Cookie、token 或含授权参数的媒体地址 | 二 |
| 关于与更新 | 突出版本与更新，折叠技术依赖信息，保留作者与许可 | 更新失败可重试；下载进度与安装状态可区分 | 三 |
| 退出与后台 | 区分关闭窗口、后台下载、暂停并退出 | 活跃任务时准确说明行为；记住选择可在设置中撤销 | 一、三 |

## 统一视觉规范

正文、辅助说明、分区标题、页面标题四层字号；沿用主题字体和系统缩放。间距采用 4、8、12、16、24 的统一尺度。避免大块顶部说明挤占内容区；长说明放在就近提示或展开区。

状态使用文字配合颜色，不以颜色作为唯一识别方式。仅可启动或继续的任务显示开始操作；删除放次级菜单或多选工具栏。空列表、搜索无结果、未登录、加载失败分别提供符合上下文的提示与行动。

最小窗口、宽窗口、浅色、深色均需验证。长中文标题和路径允许省略并查看全文；按钮不被挤出屏幕。提供清晰键盘焦点、Enter 提交和 Esc 返回；平台窗口控制遵循各平台习惯，macOS 标题栏改动需单独验证。

## 实施批次

### 第一阶段 减少误操作

第一批已落地到源码：

- [x] 范围选集支持中文逗号、空格、去重计数，检查当前列表行号，限制异常巨大范围。
- [x] 明确范围选集使用列表行号且保留已有勾选。
- [x] 解析页下载按钮及提交下载时的确认按钮显示数量。
- [x] 下载工具栏明确“列表”范围并显示列表数量；空结果禁用批量按钮。
- [x] 完成页标明清除的是记录，提示保留下载文件。
- [x] 下载选项窗口可调整大小，默认尺寸增加。
- [x] 新增文案提供简体、繁体翻译。

后续批次：

- [ ] 分组范围选集及正片、附加内容分组计数。
- [ ] 下载确认汇总质量、目录及弹幕状态；预览和按钮分行。
- [ ] 批量按钮改为可执行任务数量，补充任务多选前的删除范围确认与快照。
- [ ] 重复任务提示区分本批决策与长期偏好。
- [ ] 审计各选项的保存时机，明确取消是否撤销以及新任务生效范围。

当前按钮数量表示列表中的任务数，不代表全部任务都支持该操作；悬浮提示明确不支持的任务会跳过。批量删除仍沿用既有行为，尚未加入新的确认流程。选集仍作用于整个解析列表，尚未增加分组选择器。

### 第二阶段 提高操作效率

依次实施任务多选与错误恢复、收藏和历史的稳定入口、设置分类搜索、登录状态恢复、命名预览与诊断日志。迁移导航时保持已有功能和路由兼容，避免一次重构全部界面。

### 第三阶段 统一视觉与可访问性

统一任务行、对话框、媒体检查、关于与更新的层级和间距，再验证深浅主题、键盘流程、系统缩放和不同平台标题栏。

## 验证与发布

每批运行受影响模块的测试和静态检查。涉及选择或批量操作的变更必须验证空结果、筛选结果、混合状态、任务动态更新和取消行为。界面验证至少覆盖：解析百集内容并选取指定范围；查看附加文件后提交；筛选暂停任务并恢复；清除完成记录后确认文件仍存在。

自动化测试使用 Qt 测试配置，不操作真实账号或实际下载任务。截图测试不能替代真实窗口对深色主题、缩放和键盘焦点的验证。应用包替换在源码验证后独立执行，避免覆盖正在下载的实例。
