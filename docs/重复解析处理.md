# 重复解析与番剧条目处理

2026 年 11 月 5 日，使用 `ss33585` 实际请求番剧接口，返回 420 条：正片 100 集、更多精彩 320 条。按剧集标识去重后仍为 420 条，确认不是重复点击导致列表累加。

普通解析通过 `update_tree` 替换当前树。来源参数 `spm_id_from` 不参与番剧 season_id 提取，因此不同来源链接指向同一内容。解析完成后再次点击仍主动请求最新数据并替换列表；本轮不增加长期缓存，避免更新剧集或登录状态变化后显示旧结果。

本轮增加两项防护：

- GUI 普通解析运行期间忽略再次触发，完成或启动异常后释放状态，允许随后主动刷新。
- 接口正片和附加分组内按 ep_id 去重，缺少 ep_id 时使用 bvid 与 cid；优先保留正片位置。不同剧集即使标题相同也不会按标题合并。清理后空分组不显示。

已有下载队列不受解析列表替换影响，下载任务仍使用已有重复检测。MCP 具有自己的解析锁，本轮防重复触发针对 GUI 普通解析入口；跨 GUI 与 MCP 的统一调度仍可在后续完善。

增加测试验证跨分组重复、无 ep_id 的身份回退，以及正在运行的普通解析不会启动第二次、结束后可以再次刷新。选集时应按正片分组勾选；本轮保留附加内容，不默认隐藏或丢弃。
